Reel I

Screenings

unmaze

Format: diffusion model + browser replay · Python, PyTorch · 2.7M-parameter U-Net · 50-step DDIM · trained ~50 min on 3 CPU threads

A small diffusion model that solves hedge mazes by turning random noise into the path from the entrance to the centre. It trains on a plain CPU, and a browser page replays the model’s real frames so you can watch it work.

Why: Image models turn noise into pictures. This tests whether the same idea can turn noise into the one correct path through a maze, and measures where it stops working.

Notices

  • 5,000 fresh 11×11 mazes the model never saw: 4,990 solved (99.8%)
  • On depth-first-search mazes it never trained on: 66%
  • All 10 failures were in the longest quarter of routes; on the 300 longest routes of 30,000 it solves 93%

Credits Python · PyTorch · NumPy · Wilson’s algorithm · BFS · U-Net with self-attention · DDIM · HTML/CSS/JS

Bingo

Format: command-line movie search · Python · 5,000 films · 834-query known-item eval

A command-line movie search over 5,000 films that ranks results with keyword search, meaning-based search, or both, and can answer questions about the results with an LLM.

Why: Keyword search misses movies described in different words, and meaning-based search misses exact names. Measuring both on the same queries shows which one actually helps.

Notices

  • 834 known-item queries, test split, target in the top 10: RRF with cross-encoder reranking 0.916, BM25 0.863, plain RRF 0.837, semantic 0.626
  • Plain hybrid fusion scored below BM25 alone; only reranking beat it
  • BM25 p95 latency fell from 3.4 s to 5 ms

Credits Python · NLTK · sentence-transformers (all-MiniLM-L6-v2) · cross-encoder reranker · CLIP · Gemini 2.0 Flash · BM25 · Reciprocal Rank Fusion. Built while working through Boot.dev’s RAG course, then extended with the eval, a precomputed-statistics BM25 rewrite, and a side-by-side view of all four methods.

Open-source contributions.

better-auth: email enumeration at sign-in

2025 · Security

Signing in with an unregistered email and a compromised password returned PASSWORD_COMPROMISED instead of the generic error, revealing which emails were registered. Traced it to the Have I Been Pwned plugin throwing during the dummy-password hash, and proposed a request-scoped skip flag plus a regression test.

ShippedMaintainers adopted the approach and shipped it in #5998.

Proposal #5973 Shipped #5998

go-ethereum: geth db truncate-freezer

2025 · Systems

A subcommand for archive nodes that binary-searches the merge block, preserves headers and hashes, and drops pre-merge bodies. Reviewed across three rounds by core maintainers (s1na, jwasinger, MariusVanDerWijden); revised it to batch-process rather than hold roughly 15 GB in memory on mainnet, to move headers into a fresh freezer instead of assuming equal table lengths, and to look up merge blocks per network.

The core team built its own version of the command.
