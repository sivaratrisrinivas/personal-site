01

llmfr

  • Measured
  • CI
What
A flight recorder for LLM runs. It saves every token a local model writes, so you can replay a run and compare two runs to see the exact step where they first split.
Why
When two outputs differ, a plain text diff cannot tell you whether the cause was the seed, a sampler setting, or a cut-off context window. Everything after the first split is just fallout, and llmfr labels it that way.
How

Python, Hugging Face Transformers, a local SQLite index, and JSON traces. Commands: record, replay, compare, inspect, batch, and study. Compare never calls a model. The OpenAI adapter refuses to record when the API leaves out per-token logprobs instead of making scores up. Traces stay on your machine.

  • Pinned Qwen2.5-0.5B-Instruct demos: changing only the seed splits at token 0 (sampling); changing only temperature splits at token 8 (decoding config)
  • CPU timings over 11 runs: compare 0.151 s median, record 6.97 s median

02

Fuzz

  • Live demo
  • Measured
  • CI
What
A game where waves slowly scramble a paragraph you wrote, you type to save pieces of it, and then an AI model tries to rebuild the whole thing from what is left.
Why
It shows how diffusion models work, using words instead of pictures. Rebuilding from damage is a best guess, never an exact copy.
How

Bun and TypeScript in the browser, a FastAPI helper, and Qwen2.5 on Hugging Face. Your original text never leaves the browser. Only the scrambled version is sent, and the server rejects any request that includes the original. I also trained a LoRA adapter on Qwen2.5-0.5B with 288 synthetic examples, on CPU.

  • LoRA vs base on the locked 4-paragraph eval: word F1 on intact text 0.746 to 0.938, failed outputs 12/44 to 8/44
  • Heavily scrambled text (fuzz 0.8 to 1.0) did not improve

SunkeLo

  • Measured
  • CI
What
Ask about a product out loud in one of 11 Indian languages, and hear back one combined review built from public reviews and videos.
Why
Most useful review writing is in English or Hindi. If you think in Odia, Tamil, or Bengali, researching a purchase takes longer than it should.
How

Next.js, TypeScript, Neon Postgres, Upstash Redis, Sarvam AI for speech, translation, and summaries, and Firecrawl for scraping. Progress streams to the screen over SSE, and repeat questions come from the Redis cache. An opt-in strict mode refuses to summarize when there is too little evidence.

  • Grounding eval with 379 labeled claims showed the first word-overlap metric was wrong: it marked all 13 supported real claims as unsupported. By hand labels, 6 of 19 real claims lack source support.
  • 5-product run: 5 of 10 repeat lookups hit the cache, about Rs 0.12 per query at list price

04

SokoFlow

  • Live demo
  • Measured
  • CI
What
A small diffusion model that tries to solve box-pushing puzzles (Sokoban) by turning random moves into a plan, published next to a simple search that beats it.
Why
Image models turn noise into pictures. This tests whether the same idea can turn noise into a legal sequence of moves.
How

Python, PyTorch, and Flask. A CNN reads the 8x8 board and a Transformer denoises a 20-move plan, trained on solutions found by BFS search. It trains and runs on CPU.

  • 240 scrambled 8x8 boards: diffusion solved 6.2% (15/240), BFS solved 94.2% (226/240)
  • An earlier 20.8% figure came from easy boards. I found the cause and published the corrected number.
  • 38 hand-made Microban levels: 1 solved

05

Blast Radius

  • Measured
What
A command-line tool that finds the exact lines in your JavaScript or TypeScript code that use a vendor feature the vendor has announced it is shutting down, and shows the vendor's own notice next to each line.
Why
Shutdown notices live in changelogs nobody reads, and the code that depends on them breaks on the vendor's date. A finding is only useful if you can check it, so the tool may miss things but never reports what it cannot prove.
How

TypeScript on Node.js. Vendor notices pass five fixed checks before they count, and the scanner reads the code's syntax tree, following imports and aliases to the real vendor client. Calls it cannot resolve, like slack[method](), are reported as limits, not findings. It covers Slack, OpenAI, and Cloudflare shutdowns today.

  • Call-site matches 14/14 correct, 0 false findings across 6 decoy fixtures
  • 9/9 dynamic calls reported as limits; deadline parsing 6/6

06

Rashomon

What
A reading app where people reading the same article at the same time can highlight a passage and chat about it live, in a 5-minute room.
Why
Comment sections are slow. You leave a reaction and hope someone answers days later. This puts the conversation next to the exact passage, while the other reader is still on it.
How

Next.js, React, Tailwind, and shadcn/ui on the front end; a Bun and Elysia API on the back end. Supabase handles Google sign-in, Postgres with row-level security, and file storage. Paste a URL and the API pulls out the article text, or upload an image or PDF and Google Cloud Vision reads it. Supabase Realtime presence shows who is reading the same piece, broadcast channels carry the chat and a shared timer, and finished chats are saved so later readers can replay them from the highlighted passage.

  • Bun unit tests for the API and chat components, plus Cypress end-to-end tests for highlighting, content, and replay
  • Not deployed yet
