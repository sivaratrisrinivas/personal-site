Projects

01

unmaze

  • Measured
What
A small diffusion model that solves hedge mazes by turning random noise into the path from the entrance to the centre. It trains on a plain CPU, and a browser page replays the model’s real frames so you can watch it work.
Why
Image models turn noise into pictures. This tests whether the same idea can turn noise into the one correct path through a maze, and measures where it stops working.
How

Python, PyTorch, and NumPy. Mazes come from Wilson’s algorithm and their solutions from BFS. A 2.7M-parameter U-Net with self-attention denoises the path mask, and a DDIM sampler runs 50 steps; training took about 50 minutes on 3 CPU threads. A strict judge counts an answer only if it is exactly one simple path with no gaps or stray pixels, and no repair step runs afterward. The page is plain HTML, CSS, and JavaScript.

  • 5,000 fresh 11×11 mazes the model never saw: 4,990 solved (99.8%)
  • On depth-first-search mazes it never trained on: 66%
  • All 10 failures were in the longest quarter of routes; on the 300 longest routes of 30,000 it solves 93%

02

Bingo

  • Measured
What
A command-line movie search over 5,000 films that ranks results with keyword search, meaning-based search, or both, and can answer questions about the results with an LLM.
Why
Keyword search misses movies described in different words, and meaning-based search misses exact names. Measuring both on the same queries shows which one actually helps.
How

Python, NLTK, sentence-transformers (all-MiniLM-L6-v2), a local cross-encoder reranker, CLIP for image search, and Gemini 2.0 Flash for answers with citations. I built it while working through Boot.dev's RAG course: BM25 over an inverted index, chunked embeddings, Reciprocal Rank Fusion, and reranking. I then built an 834-query known-item eval (each query aims at one movie; queries that leak the title are dropped), rewrote BM25 to score from precomputed term statistics, and added a side-by-side view that runs all four methods on one query next to their eval scores.

  • 834 known-item queries, test split, target in the top 10: RRF with cross-encoder reranking 0.916, BM25 0.863, plain RRF 0.837, semantic 0.626
  • Plain hybrid fusion scored below BM25 alone; only reranking beat it
  • BM25 p95 latency fell from 3.4 s to 5 ms
